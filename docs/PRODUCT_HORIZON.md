# Product horizon

Status: owner-ratified direction, not an implementation schedule or ticket
ledger.

Behold's horizon is a persistent, ecologically active world that a person can
enter and that multiple independently minded characters can inhabit, change,
and leave readable histories from.

Minecraft is the present world in which Behold is learning the grain of this
problem. A person should be able to choose or compile a place, start it with
ordinary Minecraft ecology, attach differently configured resident minds, join
through the native client, watch lives unfold, stop the habitat, and later
return to the same world and lives. World changes remain
Minecraft-authoritative. Each resident's private causal history remains
portable Lync that independent readers can inspect without becoming a second
world or memory authority.

The horizon is about making truthful situated life possible, not guaranteeing
particular conduct. Survival, building, sociability, productivity, adaptation,
and culture are phenomena to observe. Behold succeeds when it provides truthful
perception, genuinely available controls, Minecraft consequences, isolated
continuity, safe operation, and legible evidence over sustained time.

## Relation to current work

[First Life](FIRST_LIFE.md) is the bounded current vertical slice. The
[sustained-habitat epic](../.tickets/beh-06av.md) and its
[multi-day acceptance](../.tickets/beh-xzc6.md) describe concrete unfinished
work. Tickets may add, close, or reorder bounded deltas; they do not expand or
shrink this product direction merely because an agent wrote them.

Place Compiler is a neighboring authority for reproducible geographic Minecraft
releases. Textile and Lync are neighboring readers and history machinery. San
Francisco is valuable terrain. None of those artifacts, and no benchmark,
viewer, tour, or evidence package, substitutes for the inhabited-world
capability.

## Owner-held decisions

The current implementation cannot decide:

- whether and where to publish a small qualified starter release;
- when to invite an independent person or machine to run the First Life entry;
- which experience, if any, should define the next compelling use after the
  bounded multi-day trial; and
- publication timing and appetite for the private alpha itself.

Until the owner decides, documentation may name these as open choices but must
not turn them into promised releases, blockers, or roadmap priority.
