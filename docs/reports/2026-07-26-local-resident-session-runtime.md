# Local resident sessions remove setup waste, not the cognition frontier

## Verdict

Behold now has a coherent local resident-session boundary: a continuing life
receives one persistent charter, an exact learned control contract ahead of
changing experience, human-scale causal working continuity, and a model that
is already resident before the shared world is released. Those mechanics are
real. They did not make the installed Llama 3.2 3B and Phi-4 pair fast enough
for ordinary Minecraft ecology, so no second Oxford run was launched.

This is not a model ranking. It is a deployment/runtime finding on this host,
these exact model artifacts, the common 16k/512 envelope, and two independent
concurrent resident requests.

## What changed

`behold.ollama-local-resident-session.v1` retains the existing strict v2 public
action schema and final Behold action validator. It does not add a retry,
correction, normalization, fallback, task, recommended action, survival reflex,
or hidden world authority.

The transport changes three session properties:

1. The persistent resident charter and exact admitted action contract are the
   first two messages. The changing own-life context and current perception
   follow them. An exact prefix hash records those bytes without claiming that
   Ollama reused a KV cache.
2. Recent working continuity is a bounded sequence of lived public tuples:
   public intention, expected consequence, chosen action and arguments, a plain
   actual terminal consequence, and coarse perception afterward. Raw controller
   `input`, `result`, and event objects; camera grids; coordinates; stable target
   identity; and provider-private reasoning are absent. The complete Lync and
   exact safe observation presentations remain authoritative.
3. The managed owner loads all exact admitted local models while Minecraft time
   is frozen, proves all pinned digests are simultaneously resident, and emits
   that setup before the all-ready release. Normal stop drains cognition, unloads
   only those owned model loads, verifies `/api/ps`, and then saves/stops the
   world. Setup loads do not consume resident quota.

The all-ready fixture exercises that complete ordering through the managed
runner: freeze, exact-envelope preload, shared release, cognition drain,
unload, save, and control release. The first real host setup loaded both pinned
artifacts at once and finished with an empty `/api/ps` inventory, but it also
exposed an implementation defect: the setup request omitted `num_ctx`, so
Ollama reserved Llama's 131,072-token default context (23.78 GB) despite the
admitted 16,384-token policy. Setup now sends the exact admitted context,
output, and temperature options and requires `/api/ps` to report the exact
context before release. That correction is fixture-exercised and has not yet
been repeated on the host.

## Exact no-world probe

The probe reconstructed two successive horizons from each retained Oxford life
and sent each round concurrently. It had no Minecraft interface and no world
authority. There were four physical local requests, no retry, correction,
normalization, substitution, provider route, or follow-up attempt.

Common settings were `num_ctx=16384`, `num_predict=512`, temperature `0.2`, and
`keep_alive=30m`. Exact installed identities were:

remained 14-24 seconds. Prompt
evaluation and constrained generation, not weight reload alone, dominate the
remaining latency. A five-second body-urgency deadline cannot admit those
results before the observed body may die and respawn.

## The working-memory falsification

The first projection was not acceptable merely because it was smaller. It fed
past actions and outcomes back as controller-shaped JSON. Llama then copied
that machinery: its first proposal nested arguments under `input` and made the
expected consequence an outcome object; its second attempted a useful public
greeting but again put a prior result object where public text was required.
Phi received six alternating camera acts as its recent demonstration and
continued the same alternation.

No tolerant unwrapping was added. The projection was repaired at its owning
boundary so the resident sees its lived conduct rather than controller wire
objects. The tests now use outcome objects containing private coordinates and
Mineflayer confirmation fields and prove none enters working continuity.
Historical conduct remains truthful—even repetitive conduct—because deleting
it to coax a better next action would be puppeteering.

## Boundaries and next risk

The corrected session boundary is supported mechanics, not behavioral success,
KV-cache proof, or the Behold endpoint. The experiment did not exercise
Minecraft, viewers, Textile, human join, world mutation, social adaptation, or
resume. It also does not show that every local inference stack or model is too
slow.

The next strategic frontier is the cognition runtime itself: actual prefix/KV
reuse, independent concurrent resident sessions, smaller body-relevant prompt
work, constrained-output cost, and credible faster local models or runtimes on
Apple Silicon. Any candidate must preserve the unchanged charter, exact
human-semantic action contract, final validator, public commitments, stale-body
rejection, independent resident attention, and ordinary Minecraft time. A
sequential queue, slowed ecology, hidden reflex policy, or late action admitted
against an obsolete body would be a false solution.
