# Cross finite model context without hiding a resident's life

Replace resident-v3's safe-but-premature byte approximation with a verified boundary over the admitted runtime wire, then let the resident explicitly enter a new context epoch and request exact bounded ranges from only its own canonical Lync life. The boundary and recall availability are resident-visible. The harness exposes coverage and limits but never chooses relevant memories, summarizes a life, steers conduct, or calls missing history Minecraft experience.

## Design

Use the admitted LM Studio model's actual prompt template, tokenizer, and loaded context length against the final resident wire, reserving output and explicit non-text perception costs. Before that exact admission is available, fail closed. At the first request that cannot carry the full chronological transcript, begin a versioned resident-visible context epoch bound to entity, canonical selected tip, covered sequence range, prior epoch, and reason. Keep recent post-boundary chronology normally. Expose an entity-closure-bound continuity operation for exact canonical turn ranges; do not accept entity/loom/path/tip from the model. Return only complete resident-visible transcript turns with authenticated range/tip bindings, byte limit, complete/incomplete coverage, and continuation. Record the boundary and recall outcome in that resident's own chronological life without describing Lync retrieval as a Minecraft consequence. Literal search is follow-up only if measured range navigation is insufficient.

## Acceptance Criteria

A sentinel-rich adversarial life proves every interior turn is present in order in the actual outbound wire until the admitted model's exact verified boundary; no provider-side or Behold-side middle truncation is accepted. At the boundary no partial transcript is sent: the resident receives an explicit versioned epoch transition and an exact catalog of its own available life range. A deterministic resident can choose arbitrary old ranges and receives only the exact resident-visible projection of those canonical turns, with whole-turn paging and visible continuation; the harness performs no relevance selection or summary. Foreign entity/tip/path requests, stale or tampered sources, out-of-range access, and oversized items fail visibly. Stop/resume reproduces the same epoch identity and recall bytes from canonical Lync as uninterrupted continuation. Two isolated residents sharing one physical LM Studio instance never receive each other's private canaries. Retained controller state and each recall page remain bounded. Finally, the same mature Oxford lives cross this boundary through ordinary behold live, stop, resume, exact request inspection, and Textile-readable canonical histories; whether the real model requests or uses recall well is conduct.
